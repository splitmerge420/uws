# INV-013: Post-Quantum Readiness

| Field | Value |
|---|---|
| **ID** | INV-013 |
| **Severity** | mandatory |
| **Status** | active |
| **Registry key** | `INV-13` in `toolchain/invariants_registry.py` |

## Statement

Cryptographic systems must support or plan for NIST PQC algorithms (ML-KEM-768,
ML-DSA-65 / Dilithium).

## Rationale

Harvest-now-decrypt-later attacks are already occurring.  Any data encrypted today with
classical algorithms (RSA, ECDSA) is at risk once a sufficiently powerful quantum
computer exists.  NIST finalized ML-KEM and ML-DSA in 2024; systems must have a
migration path.
