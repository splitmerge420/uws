# INV-002: Consent Gating

| Field | Value |
|---|---|
| **ID** | INV-002 |
| **Severity** | critical |
| **Status** | active |
| **Registry key** | `INV-2` in `toolchain/invariants_registry.py` |

## Statement

All state-changing operations require explicit consent before execution.

## Rationale

A state-changing operation that proceeds without explicit consent is indistinguishable
from an attack.  Consent gating is the mechanical implementation of user sovereignty
(INV-001): every write, delete, create, update, send, or modify must be preceded by an
unambiguous approval signal from the user or a fully audited automated-consent rule that
the user has pre-approved.

## Implementation

| File | Symbol | Role |
|---|---|---|
| `src/constitutional_engine.rs` | `check_consent_gating()` | Core runtime check — blocks writes without `user_consent` |
| `src/council_github_client.rs` | `CouncilGitHubClient::execute()` | Step 2 of execution pipeline |
| `src/executor.rs` | `dry_run` flag | Dry-run prevents execution; user must explicitly drop the flag |
| `toolchain/invariants_registry.py` | `INVARIANTS["INV-2"]` | Canonical registry entry with guard/danger patterns |
| `toolchain/invariant_linter.py` | `InvariantLinter.lint_file()` | Static analysis using guard_check logic |

## Dangerous Patterns

```rust
// Calling a mutating API without consent check
fn delete_file(id: &str) {
    http_client.delete(id);   // ← VIOLATION: no consent gate
}
```

```python
os.remove(path)                         # ← VIOLATION: no consent check
subprocess.run(["rm", "-rf", path])     # ← VIOLATION
```

## Guard Patterns

Compliant code must contain at least one of:
`consent`, `authorize`, `approve`, `confirm`,
`validate_permission`, `ConsentManager`, `consent_manager`, `auto_consent`

## Test Vectors

| Scenario | Expected |
|---|---|
| `user_consent = false`, operation = `"delete"` | `check_consent_gating` returns `passed: false` |
| `user_consent = true`, operation = `"delete"` | returns `passed: true` |
| `--dry-run` flag set | execution blocked; no consent needed |
| Non-mutating read with no consent | returns `passed: true` |
