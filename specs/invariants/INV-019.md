# INV-019: Jurisdictional Compliance

| Field | Value |
|---|---|
| **ID** | INV-019 |
| **Severity** | critical |
| **Status** | active |
| **Registry key** | `INV-19` in `toolchain/invariants_registry.py` |

## Statement

Data storage and processing must comply with the union set of all applicable
jurisdictional requirements (GDPR, CCPA, HIPAA, PIPEDA, etc.).

## Rationale

"We only comply with the strictest single law" is insufficient: a user may be subject
to multiple overlapping regimes simultaneously (e.g., an EU citizen working in
California with health data).  The union-set principle (INV-033) requires applying all
applicable laws concurrently.

## Key Regulations

| Regulation | Key Requirements |
|---|---|
| GDPR (EU) | Consent, right to erasure, portability, 72h breach notification |
| CCPA (California) | Opt-out of sale, right to know, right to delete |
| HIPAA (US health) | PHI safeguards, minimum necessary, BAA required |
| PIPEDA (Canada) | Consent, limited collection, accuracy |
