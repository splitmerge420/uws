# INV-023: Test Coverage

| Field | Value |
|---|---|
| **ID** | INV-023 |
| **Severity** | mandatory |
| **Status** | active |
| **Registry key** | `INV-23` in `toolchain/invariants_registry.py` |

## Statement

All critical paths must have unit tests. Target 80 %+ coverage on governance code.

## Rationale

Untested code is broken code waiting to be discovered.  The 80 % floor on governance
code (invariant enforcement, consent gating, audit logging) ensures the most
security-critical paths are continuously validated.  Tests also serve as executable
documentation.

## Implementation

| File | Symbol | Role |
|---|---|---|
| `tests/` | Integration tests | End-to-end CLI tests |
| `src/**/*.rs` `#[cfg(test)]` | Unit tests | Inline unit tests per module |
| `toolchain/` `pytest` | Python unit tests | `test_*.py` files |
| `.github/workflows/ci.yml` | `cargo test` | Runs on every push and PR |
| `.github/workflows/coverage.yml` | Coverage report | Tracks coverage over time |
| `toolchain/invariants_registry.py` | `INVARIANTS["INV-23"]` | Canonical registry entry |

## Coverage Targets

| Code area | Minimum coverage |
|---|---|
| Governance (invariant enforcement, consent) | 80 % |
| Authentication | 70 % |
| API execution | 60 % |
| Formatters, utilities | 50 % |

## Test Vectors

| Scenario | Expected |
|---|---|
| New invariant enforcement function with no test | mandatory violation |
| `cargo test` passes with zero failures | pass |
| Governance code coverage < 80 % | mandatory violation |
