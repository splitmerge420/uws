# INV-016: Data Minimization

| Field | Value |
|---|---|
| **ID** | INV-016 |
| **Severity** | mandatory |
| **Status** | active |
| **Registry key** | `INV-16` in `toolchain/invariants_registry.py` |

## Statement

Collect only the minimum data necessary for the operation.

## Rationale

Every datum collected is a liability: it must be stored, protected, classified, and
eventually deleted.  Data minimization reduces attack surface, simplifies compliance
(GDPR Art. 5(1)(c)), and respects user privacy by default.

## Implementation

| File | Symbol | Role |
|---|---|---|
| `src/executor.rs` | `--params fields=...` | Encourages `fields` param to request only needed fields |
| `toolchain/invariants_registry.py` | `INVARIANTS["INV-16"]` | Canonical registry entry |

## Applied at Integration Level

Each integration manifest must declare its minimum required scopes (no overly broad
scopes like `https://www.googleapis.com/auth/drive` when
`https://www.googleapis.com/auth/drive.readonly` suffices).

## Test Vectors

| Scenario | Expected |
|---|---|
| Integration requests `*.admin` scope for a read-only operation | advisory violation |
| API call requests all fields when only 2 are used | advisory violation |
| `--params '{"fields": "id,name"}'` used to limit response | pass |
