# INV-017: Right to Delete

| Field | Value |
|---|---|
| **ID** | INV-017 |
| **Severity** | critical |
| **Status** | active |
| **Registry key** | `INV-17` in `toolchain/invariants_registry.py` |

## Statement

Users must be able to delete all their data, including backups, within 72 hours of
request.

## Rationale

The right to erasure (GDPR Art. 17, CCPA) is a legal requirement in many jurisdictions
and a fundamental privacy right everywhere.  The 72-hour window aligns with GDPR breach
notification requirements, making it operationally natural.  Data that cannot be deleted
is data that cannot be controlled.

## Implementation

| File | Symbol | Role |
|---|---|---|
| `src/credential_store.rs` | `CredentialStore::delete()` | Deletes locally stored credentials |
| `src/auth_commands.rs` | `auth logout` | Triggers credential deletion |
| *(future)* | `uws data purge --all` | Full user-data purge command |
| `toolchain/invariants_registry.py` | `INVARIANTS["INV-17"]` | Canonical registry entry |

## Deletion Checklist

A compliant delete implementation must cover:

- [ ] Active credentials and tokens
- [ ] Cached Discovery Documents containing user-specific data
- [ ] Audit logs (with jurisdictional exception logging)
- [ ] Any third-party provider data via provider delete APIs
