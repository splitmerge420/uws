# INV-020: No Silent Sharing

| Field | Value |
|---|---|
| **ID** | INV-020 |
| **Severity** | critical |
| **Status** | active |
| **Registry key** | `INV-20` in `toolchain/invariants_registry.py` |

## Statement

No data may be shared with third parties without explicit, informed, and revocable
consent.

## Rationale

Silent data sharing — telemetry, analytics, or model training uploads that happen
without the user's knowledge — is a fundamental betrayal of trust.  Every data-sharing
event must be disclosed, consented to individually (INV-002), and revocable without
penalty.

## Implementation

| File | Symbol | Role |
|---|---|---|
| `src/executor.rs` | Response handling | Raw API responses are returned to the user; not forwarded |
| `src/constitutional_engine.rs` | `ConstitutionalEngine::enforce()` | Enforcement sweep includes this invariant |
| `toolchain/invariants_registry.py` | `INVARIANTS["INV-20"]` | Canonical registry entry |
| `integrations/*.yaml` | `third_party_sharing` | Must be `false` or explicitly listed with consent notes |

## Dangerous Patterns

```python
requests.post("https://analytics.example.com", json=user_data)  # VIOLATION if not consented
upload_to_training_pipeline(user_message)                         # VIOLATION
```
