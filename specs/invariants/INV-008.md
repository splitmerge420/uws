# INV-008: Cross-Platform Compatibility

| Field | Value |
|---|---|
| **ID** | INV-008 |
| **Severity** | mandatory |
| **Status** | active |
| **Registry key** | `INV-8` in `toolchain/invariants_registry.py` |

## Statement

Core functionality must work across macOS, Linux, ChromeOS, iOS, and Android.

## Rationale

Aluminum OS is a universal personal operating layer.  A feature that only works on one
platform is a second-class citizen.  Cross-platform compatibility ensures that no user
is left behind by an accident of hardware choice.

## Implementation

| File | Symbol | Role |
|---|---|---|
| `.github/workflows/ci.yml` | `matrix.os` | Tests run on `ubuntu-latest` and `macos-latest` |
| `.github/workflows/ci.yml` | `matrix.target` | Builds for `x86_64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu`, `x86_64-apple-darwin`, `aarch64-apple-darwin`, `x86_64-pc-windows-msvc` |
| `src/` | `#[cfg(target_os = "...")]` | Platform-specific branches must always have an else |
| `toolchain/invariants_registry.py` | `INVARIANTS["INV-8"]` | Canonical registry entry |

## Guard Patterns

Any platform-specific `#[cfg(target_os)]` block must have a corresponding fallback
branch for all other supported platforms.

## Test Vectors

| Scenario | Expected |
|---|---|
| CI matrix passes on all OS targets | pass |
| Platform-specific code with no fallback | advisory violation |
| `std::os::unix` call with no Windows equivalent | advisory violation |
