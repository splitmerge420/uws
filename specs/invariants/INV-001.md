# INV-001: User Sovereignty

| Field | Value |
|---|---|
| **ID** | INV-001 |
| **Severity** | critical |
| **Status** | active |
| **Registry key** | `INV-1` in `toolchain/invariants_registry.py` |

## Statement

The user is the ultimate authority. No AI agent may override explicit user decisions.

## Rationale

Aluminum OS exists to augment human capability, never to supplant human judgment.  Any
system that can silently override a user's explicit decision is an adversary, not a tool.
This invariant is the root of all others: without it, consent gating (INV-002), audit
trails (INV-003), and data sovereignty (INV-026) are all meaningless.

## Dangerous Patterns

Code that violates this invariant typically looks like:

```python
# Agent overriding user's explicit "no"
if not user_approved:
    force_execute(op)   # ← VIOLATION

# Silent default that ignores user preference
result = user_setting or AGENT_DEFAULT   # ← VIOLATION if AGENT_DEFAULT overrides
```

## Guard Patterns

Compliant code must contain at least one of:
`user_approved`, `user_consent`, `explicit_user_decision`, `UserSovereignty`
