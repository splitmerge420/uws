# INV-005: Constitutional Authority

| Field | Value |
|---|---|
| **ID** | INV-005 |
| **Severity** | critical |
| **Status** | active |
| **Registry key** | `INV-5` in `toolchain/invariants_registry.py` |

## Statement

Dave Protocol: the designated sovereign has veto power on all Critical-severity rules.

## Rationale

A distributed multi-agent system needs a single human locus of ultimate authority for
Critical-severity decisions.  The "Dave Protocol" names this authority explicitly so
that every agent on the Pantheon Council knows who holds the constitutional veto.  This
invariant prevents rule-by-committee deadlock and ensures accountability cannot be
diffused across the council.

## Approval Token Format

```yaml
council_approval:
  token: "dave-approved-YYYY-MM-DD"
  approver: "Dave Sheldon"
  timestamp: "2026-03-20T19:00:00Z"
```

## Test Vectors

| Scenario | Expected |
