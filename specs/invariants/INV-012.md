# INV-012: Encryption in Transit

| Field | Value |
|---|---|
| **ID** | INV-012 |
| **Severity** | critical |
| **Status** | active |
| **Registry key** | `INV-12` in `toolchain/invariants_registry.py` |

## Statement

All network communication must use TLS 1.3+ or equivalent.

## Rationale

Unencrypted network traffic is trivially intercepted.  TLS 1.3 removes obsolete cipher
suites and handshake round-trips, making it both more secure and faster than previous
versions.

## Implementation

| File | Symbol | Role |
|---|---|---|
| `src/client.rs` | HTTP client construction | Uses `reqwest` with default TLS; must not disable certificate verification |
| `toolchain/invariants_registry.py` | `INVARIANTS["INV-12"]` | Canonical registry entry with forbidden patterns |

## Forbidden Patterns

```python
http://api.example.com/...   # ← VIOLATION (non-localhost plain HTTP)
verify=False                  # ← VIOLATION (disables TLS cert verification)
```

Exception: `http://localhost`, `http://127.0.0.1`, `http://0.0.0.0` are permitted for
local development and testing.
